# 🏦 Banco Puertollano 2027

Proyecto realizado en **Python** para trabajar programación orientada a objetos, gestión de ficheros, excepciones y generación de logs.

## 📥 Clonar el proyecto

```bash
git clone URL_DEL_REPOSITORIO
```

Después entra en la carpeta:

```bash
cd bancoPuertollano2027
```

## 🪟 Windows

```bash
python -m venv .venv
```

Activar:

```bash
.venv\Scripts\activate
```

## 🍎 macOS

```bash
python3 -m venv .venv
```

Activar:

```bash
source .venv/bin/activate
```

## 📦 Instalar dependencias

```bash
pip install -r requirements.txt
```

## ▶️ Ejecutar

### Windows

```bash
python main.py
```

### macOS

```bash
python3 main.py
```


## 📝 Logs

Los logs se generan con el formato:

```text
AAAAMMDD-banco.log
```

Por ejemplo:

```text
20260930-banco.log
```

## 🔄 Actualizar el proyecto

```bash

```

```bash
deactivate
```
